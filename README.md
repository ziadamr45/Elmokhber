## 📖 نبذة

<div dir="rtl">

**المخبر** هي لعبة اجتماعية تفاعلية ملهمة من ألعاب الاستنتاج الاجتماعي الشهيرة مثل Mafia و Werewolf. يلعب المشاركون أدوارًا مخفية — بعضهم يحاول كشف الخائن والبعض الآخر يحاول الخداع والنجاة. اللعبة تعتمد على الذكاء، الفهم، القراءة النفسية، والخداع الاستراتيجي في جو مليء بالإثارة والتشويق.

التطبيق مبني كمنصة ويب تفاعلية تدعم اللعب متعدد اللاعبين في الوقت الحقيقي مع مكالمات صوتية مباشرة.

## 🚀 التشغيل

### المتطلبات

- Node.js 18+ أو Bun
- npm أو yarn أو bun

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/ziadamr45/Elmokhber.git
cd Elmokhber

# تثبيت التبعيات
npm install
# أو
bun install

# إعداد متغيرات البيئة
cp .env.example .env
# عدّل ملف .env بإعدادات LiveKit وقاعدة البيانات

# تشغيل تهجيرات قاعدة البيانات
npx prisma migrate dev

# تشغيل خادم التطوير
npm run dev
```

التطبيق سيعمل على `http://localhost:3000`

## English


**Elmokhber** is a social deduction game inspired by classic games like Mafia and Werewolf. Players take hidden roles — some try to uncover the traitor while others try to deceive and survive. The game relies on intelligence, perception, psychological reading, and strategic deception in a thrilling atmosphere.

The app is built as an interactive web platform supporting real-time multiplayer gameplay with live voice calls.

| 🎨 Modern & attractive design | Elegant and modern interface |

### Getting Started

#### Prerequisites

- Node.js 18+ or Bun
- npm, yarn, or bun

#### Installation

```bash
# Clone the repository
git clone https://github.com/ziadamr45/Elmokhber.git
cd Elmokhber

# Install dependencies
npm install
# or
bun install

# Set up environment variables
cp .env.example .env
# Edit .env with your LiveKit and database configuration

# Run database migrations
npx prisma migrate dev

# Start development server
npm run dev
```

The app will be available at `http://localhost:3000`

### How to Play

1. **Create or join a room** — Share the room code with friends
2. **Role assignment** — Each player receives a secret role
3. **Game starts** — Discuss and discover who the traitor is
4. **Voting** — Vote to eliminate suspects
5. **Win** — The team that discovers the traitor first wins!
